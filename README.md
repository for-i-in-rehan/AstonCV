# AstonCV

AstonCV is a web-based application for creating and managing CVs (Curriculum Vitae). This project includes a user-friendly interface for users to register, log in, and manage their CV information. The application is built using PHP and styled with CSS.

## Features

- User registration and login system
- CV creation and management
- Responsive design with custom CSS

## Installation

1. **Clone the repository**

    ```bash
    git clone https://github.com/yourusername/AstonCV.git
    cd AstonCV
    ```

2. **Set up your web server**

    Make sure you have a web server (like Apache) with PHP installed. Place the project files in the server's root directory.

3. **Database Setup**

    - Create a MySQL database for the application.
    - Import the provided SQL file to set up the necessary tables.
    - Update the database connection settings in the PHP files if needed.

4. **Run the Application**

    Access the application via your web browser at `http://localhost/` (or your server's domain).

## Usage

- Register a new user account.
- Log in with your credentials.
- Create and manage your CV information through the provided interface.

## File Structure

- `CV.php` - Main CV management page.
- `home.php` - Home page of the application.
- `register.php` - User registration page.
- `CSS/` - Directory containing all CSS files for styling the application.
